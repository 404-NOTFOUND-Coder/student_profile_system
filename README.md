# 学生用户画像系统

> 基于 Vue 3 的学生多维画像系统，采用纯前端模拟数据展示

## 📋 项目概述

本系统是一个面向高校的学生用户画像平台，通过模拟数据展示学生的学业成绩、课外活动、获奖情况等多维度画像，为教育教学管理提供数据支撑。

**当前版本：纯前端演示版（所有数据均为模拟数据）**

### 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + Element Plus | 现代化组件化开发 |
| 构建工具 | Vite | 快速开发服务器 |
| 图表 | ECharts | 数据可视化 |

## 🚀 快速开始

### 环境要求

- Node.js 18+

### 启动前端服务

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 访问系统

- 前端地址: http://localhost:3000

## 📊 核心功能

### 1. 学生档案管理

- 学生信息的查看
- 多条件筛选
- 学生画像详情查看

### 2. 学生画像分析

#### 画像类型分类

| 类型 | 特征描述 |
------|---------|
| 学术研究型 | GPA 高、知识深度好、科研能力强 |
| 实践应用型 | 活动丰富、实践能力强、创新意识强 |
| 复合探索型 | 全面发展、兴趣广泛、综合素质高 |

#### 核心量化指标

| 指标 | 说明 |
------|-----|
| 知识结构熵 | 衡量知识面广度 |
| 图编辑距离 | 与标准培养方案的偏离程度 |
| 综合评分 | 综合素质评估 |

### 3. 活动管理

- 查看各类课外活动
- 活动分类筛选
- 活动详情展示

### 4. 活动推荐

- 个性化活动推荐
- 推荐理由展示
- 活动分类浏览

### 5. 学业预警

- 成绩预警（GPA 低于阈值）
- 学分预警（未修满规定学分）
- 预警处理追踪

### 6. 数据分析

- 学生分布统计
- 成绩分析
- 画像类型分析
- 预警分析

### 7. 知识图谱

- 图谱视图
- 四元组视图
- 统计信息展示

## 📝 模拟数据说明

本系统所有数据均为前端模拟数据，包括：

- **学生数据**：100个模拟学生信息
- **画像数据**：完整的学业分析、证据链、时间线
- **活动数据**：各类课外活动、比赛信息
- **预警数据**：学业预警记录
- **图谱数据**：学生关系图谱
